StreamForge Creator Suite Documentation

A structured documentation sample demonstrating DITA XML authoring, information architecture, and publishing to HTML5, WebHelp, and PDF.

Project Overview

This project presents a structured technical documentation workflow for the StreamForge Creator Suite. The sample demonstrates how modular documentation topics can be organized and published into multiple delivery formats from a common documentation architecture.

The published outputs include web-based documentation, searchable WebHelp, and downloadable PDF documentation.

Documentation Workflow

1. Structured Source DITA XML topics and supporting assets.
2. DITA Map Topic organization, hierarchy, navigation, and relationships.
3. Authoring and Publishing Oxygen XML and the selected publishing workflow.
4. Delivery Formats HTML5, WebHelp, and PDF outputs.

Repository Structure

The project is organized so that the portfolio page remains separate from the generated documentation outputs.

Recommended structure: 

streamforge/
├── index.html
├── README.md
├── html/
├── webhelp/
├── pdf/
└── source/

Keep the complete HTML5 and WebHelp output folders together with their CSS, JavaScript, images, search files, and other dependencies.
