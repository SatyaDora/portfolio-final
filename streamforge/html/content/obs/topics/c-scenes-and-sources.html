Scenes and Sources

How OBS Studio's scene and source model works.

A scene is a named collection of one or more sources—windows, cameras, images, or other on-screen elements—arranged together on a canvas. Switching scenes changes everything visible on screen at once, instead of repositioning sources one at a time.

Most products let you build multiple scenes ahead of time and switch between them during a session or recording.

OBS Studio supports eleven source types, covering screen and window capture, game capture, camera and audio devices, images, media files, browser content, text, solid color, slideshows, and VLC-based playlists. Each source type has its own properties dialog with settings specific to that source.

Sources can be resized, cropped, and layered within a scene using the same transform handles regardless of source type, and the same source can be reused across multiple scenes without duplicating its underlying capture.
