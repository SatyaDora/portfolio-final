Hotkeys

Default global keyboard shortcuts, all of which are user-configurable.

Action Default hotkey
Start/Stop Streaming Not bound by default
Start/Stop Recording Not bound by default
Save Replay Buffer Not bound by default
Switch to Scene 1-9 Not bound by default
Push-to-talk / Push-to-mute Not bound by default

All hotkeys are unbound out of the box to avoid conflicting with other applications; assign them from Settings > Hotkeys.
