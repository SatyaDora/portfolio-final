Installing OBS Studio

Download and install OBS Studio on Windows, macOS, or Linux.

A 64-bit system meeting System Requirements.

The installer differs slightly per platform, but the first-run experience is the same everywhere: an Auto-Configuration Wizard benchmarks your hardware and proposes starting output settings.

  1. Download the installer for your platform from the official OBS Studio site.
    Windows
    Run the .exe installer and accept the default install location unless you have a reason to change it.
    macOS
    Open the .dmg and drag OBS Studio into Applications.
    Linux
    Install via the distribution's package manager, Flatpak, or the official PPA, depending on your distribution.
  2. Launch OBS Studio for the first time.
  3. Complete the Auto-Configuration Wizard.
    Choose Optimize for recording or Optimize for streaming depending on your primary use, then accept the benchmarked settings or adjust them.
OBS Studio opens with a default scene collection and one empty scene, ready for you to add sources.
